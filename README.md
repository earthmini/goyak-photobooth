# 고약네컷 — 제5회 고약인의 밤 포토부스

서버 없이 **정적 웹페이지(URL)** 만으로 동작하는 아이패드 포토부스입니다.

## 실행 (서버 설치 불필요)

아무 정적 호스팅에 폴더를 올리거나, 로컬에서 정적 서버만 켜면 됩니다.

```bash
cd ~/goyak-photobooth

# 예시 1) Python (내장만 사용, 앱 서버 코드 없음)
python3 -m http.server 8080

# 예시 2) VS Code / Cursor Live Preview, Netlify Drop, GitHub Pages 등
```

아이패드에서는 같은 Wi‑Fi의 `https://…` 또는 호스팅 URL로 접속하세요.  
(카메라 권한은 **HTTPS** 또는 localhost에서만 동작합니다.)

## 캔버스 / 프레임

| 항목 | 값 |
|------|-----|
| 인쇄 | **100 × 148 mm** |
| 합성 캔버스 | **1080 × 1920** (제공 프레임 원본) |
| 사진 칸 | 4개 · **466 × 668** @ (64,78) (550,78) (64,754) (550,754) |
| 프레임 | `frames/frame1~5.png` 고정 5종 (추가 업로드 없음) |

## 흐름

1. 시작 — 출력 매수 → 시작하기  
2. 프레임 선택 — 흰색 / 검은색 / 추가 (미리보기 없음)  
3. 촬영 — 5초 카운트 × 8장, 화면·오버레이에 `n/8` 표시  
4. 선택 — 8장 중 4장  
5. 합성 — 고해상도 + **하단 QR 영역 할당**, 화면에도 QR 표시  
6. 인쇄 — CP1500 4×6 → 초기 화면  

## QR 다운로드

- 합성 이미지 **하단 오른쪽**에 QR을 그립니다.
- 가능하면 24시간 임시 공개 링크를 만들고, 실패 시 같은 페이지의 로컬 뷰어(`?v=…`)로 연결합니다.
- 인쇄 화면의 **사진 저장**으로도 받을 수 있습니다.

## 행사용 프레임

- 권장 크기: **1181 × 1748** (100×148mm @300dpi)
- 사진 자리만 투명한 PNG 오버레이를 권장합니다.
